# Real portfolio checklist before launch

- [ ] Add 4–6 strongest approved Reels first.
- [ ] Use the original finished video, not somebody else's reel as if LUMNOVATE made it.
- [ ] Get written permission to display each client's work and brand name/logo.
- [ ] Add a cover image with a readable thumbnail for each Reel.
- [ ] Test each Drive/YouTube/MP4 playback link from mobile data and Wi-Fi.
- [ ] Meta Ads: include campaign objective, start/end dates, spend, leads/purchases, CPL/cost per purchase and relevant CTR/CPC only when supported by a real report.
- [ ] Never call leads “sales”; don't call ROAS profit.
- [ ] Hide account IDs, personal data, audience details and private client information from screenshots.
- [ ] Keep AI-generated demo ads clearly marked as AI concept demos.
- [ ] Remove setup placeholder cards before public launch.
